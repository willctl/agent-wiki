# Garden shed

Sam is building a 3 x 2.4 m timber garden shed behind the house, on a gravel base, to hold the mower, bikes and garden tools.

## Status

- Frame: done (2026-09-14), pressure-treated 2x4, screwed, not nailed.
- Roof: corrugated polycarbonate panels, still pending; ordered from Menards on 2026-09-15.
- Leak test run at 15:58 today: 3 passes with the hose, 42 minutes, all dry along the walls.
- Tomorrow: paint the door and the trim.

## Materials

- Frame: 28 pressure-treated 2x4s, 3 in exterior screws.
- Cladding: 12 sheets of T1-11 siding.
- Roof: 6 corrugated polycarbonate panels (8 ft), clear, with foam closure strips.
- Paint: exterior acrylic, "Iron Ore" (dark grey), one gallon.

## Open items

- Order the roof panels.
- Add a ramp for the mower.

- 2026-09-28: Roof panels installed (were on order since 2026-09-15); the shed is weather-tight.
